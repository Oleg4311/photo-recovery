Photo Recovery 0.7

Запускайте приложение ярлыком «Photo Recovery» на рабочем столе
или через меню «Пуск». Python отдельно устанавливать не нужно.

Выберите диск слева и раскройте папку либо нажмите «Выбрать папку…».
Для прямого чтения подтвердите запрос Windows на доступ администратора.
Также можно работать с несжатым образом RAW, DD или IMG.

Нажмите «Сканировать». Разверните дерево или
найдите запись по имени / пути. Выберите файл или папку и нажмите
«Глубоко восстановить». Ctrl / Shift позволяют выбрать
несколько записей. Общий поиск находится в меню «Инструменты».

Путь сохранения заполнен автоматически, его можно изменить внизу окна.
Папка создаётся при восстановлении. Сканирование не сохраняет файлы.
Сохранение на исходный физический диск блокируется: нужен другой
накопитель или подходящая сетевая папка.

Все типы файлов можно извлечь по сохранившемуся размещению.
Глубокая сборка фрагментов реализована для baseline JPEG, PNG,
ZIP и Office в формате ZIP (DOCX, XLSX, PPTX). Для остальных типов
целостность извлечённого файла не подтверждается. «Глубоко» не
означает, что уже перезаписанные байты можно вернуть.
Для разнесённых фрагментов увеличьте окно поиска до 16–32 МиБ.

Результаты, исходные диапазоны и SHA-256 записываются в отдельную
папку сеанса с журналом report.jsonl. Для реального носителя
сохраняйте восстановленные файлы на другой исправный накопитель.

Удаление: Параметры Windows → Приложения → Установленные
приложения → Photo Recovery → Удалить.

Отчёт о проверке: Документация\V05-REPORT.md в папке приложения.
CLI: CLI\PhotoRecoveryCLI.exe в папке приложения.
