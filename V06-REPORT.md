# Photo Recovery 0.6

Интерфейс: слева диски и раскрываемые папки, в центре удалённые записи и результаты, справа сведения и предпросмотр. Доступны выбор папки диалогом и обновление подключённых устройств. Список томов Windows доступен без CIM.

«Сканировать» читает каталог без сохранения файлов и без создания папки результатов. Для прямого чтения удалённых записей приложение предлагает повышение прав. Выбранная папка ограничивает результаты и восстановление известным исходным путём; записи с потерянным путём к ней не приписываются.

Назначение заполнено автоматически: Photo Recovery/Recovered в профиле пользователя. Его можно изменить. Папка создаётся при восстановлении после проверки назначения. Сохранение на исходный физический диск запрещено; просмотр и сканирование при этом доступны. Для восстановления с единственного диска C нужен другой накопитель или подходящее сетевое расположение.

Выбранные записи восстанавливаются отдельными кнопками обычного и глубокого восстановления. Восстановление всего диска и дополнительные параметры находятся в меню «Инструменты».

Проверено: 26 тестов движка; GUI-проверка каталога, глубокого восстановления JPEG и произвольного файла; отдельная GUI-проверка реального списка томов и раскрытия C:/Users, сканирования без создания назначения, ограничения выбранной папкой и автоматического создания назначения при восстановлении.

Ограничения движка остаются прежними: извлечение произвольных типов по метаданным не означает универсальную сборку фрагментов. Структурная глубокая сборка поддерживает JPEG, PNG и ограниченные ZIP/Office. Подробности в документации 0.5.
