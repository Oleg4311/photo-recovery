# Photo Recovery 0.7

- Светлая тема с единой палитрой таблиц, вкладок, полей, меню и состояний кнопок. Удалённые записи — тёмно-красный текст на белом фоне.
- NTFS не отбрасывает накопленный каталог при достижении лимита. Частичный результат и отмена сохраняют прочитанные записи.
- Поиск выбранной папки проверяет родительские записи MFT по мере необходимости с ограниченным кэшем, вместо хранения всех посторонних каталогов диска. Номера последовательности родительских записей проверяются.
- Восстановление выбранного также строит ограниченный каталог выбранных записей вместо накопления полного списка диска.

Путь сохранения заполнен автоматически, сканирование не создаёт папку результатов. Сохранение на исходный физический накопитель запрещено.

Проверки: малый лимит с ранними посторонними файлами и каталогами и поздним целевым файлом; частичный каталог при отмене; обычное и глубокое восстановление выбранного; GUI-навигация C, сканирование без создания назначения и ограничение папкой; снимок окна для визуальной проверки темы. Результат проверки реального C:/Users/olegb/Videos — benchmark/v07-real-catalogue.json.

Ограничения восстановления произвольных типов и поддерживаемой глубокой сборки остаются прежними (документация 0.5).
